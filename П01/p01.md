Граница: класс Account, управляющий денежным балансом.
Контракт: Balance только для чтения; Deposit/Withdraw принимают положительные суммы; Withdraw не уводит в минус.
Инвариант: balance >= 0.
Ошибки: отрицательный initial - ValueError; неположительная сумма - ValueError; недостаточно средств - RuntimeError.
Инвариант держит сам класс через name mangling (__balance) и проверки в методах.
В C# инвариант защищён private-полем и компилятором; в Python - договором:
acc._Account__balance = -100 технически возможно, но требует знать mangled-имя.
