Если у объекта нет __enter__/__exit__, with бросит TypeError в момент
выполнения with (а не при создании объекта) - это выяснится сразу,
на первой же строке with. Ошибка внутри блока не мешает закрытию файла,
потому что __exit__ вызывается в любом случае; return False пробрасывает
исключение дальше.
